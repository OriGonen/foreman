06 · Dry run

foreman dry-run: a walk round before work starts. No prompt is sent and no sandbox starts, so it is free. It shows what would run, the settings (exec, model, effort, permissions, live, the three budgets, where the logs go) and the exact prompt for the first ticket. Data: the new foreman dry-run --json, which carries the prompt as a string; the app shows it as text with line numbers.

Pick: a · settings beside the prompt. The prompt is the long part and the reason to open a dry run; side by side, it can be read at full height while the settings stay in view. A window is wide where a terminal is tall, so the terminal's stacked order (b) wastes the width and pushes the prompt below the fold.
