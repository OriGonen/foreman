10 · The install wizard (terminal)

bash install.sh asks one question when — and only when — stdin and stdout are both terminals: CLI only, or CLI + desktop app. Everywhere else (the smoke suite captures its output; CI; a pipe) it behaves exactly as today. --gui / --no-gui answer it up front for scripted installs. On a rerun it asks only about the missing piece; with everything installed it asks nothing. Installed-or-not is read from disk: gui/node_modules and the Start-menu shortcut.

This is terminal output, so it uses the terminal's own palette (ADR 0003) whatever the window's background; a and a2 show it on a dark and a light terminal. The header is drawn only in a 256-colour or 24-bit terminal at least 80 columns wide; a 16-colour or narrower terminal, or one without colour, gets the same words as plain lines.

Pick: a · numbered choice, with a new header at sign-off: a mini-scene in the half-block style of lib/foreman-draw.cjs. The sun stands high and whole, and the foreman's silhouette (hard hat, hands on hips) stands against it on the lit plain, his shadow running toward you. It is 12 rows by 36 columns, with FOREMAN install beside it; its exact pixels are below. Typing 1 or 2 works with a plain read in any terminal, Git Bash's mintty included; b's arrow-key menu needs raw key reading in bash, which foreman avoids everywhere but the run's own status bar — and it looks no better for one question.
The header's exact pixels

24 pixel rows by 36, two to a terminal row, as halfBlocks and encode in lib/foreman-draw.cjs draw them: ▀ with the top pixel as foreground and the bottom one as background, █ when both match, ▄ when only the bottom one is set, a space when neither is. Colours: y sun, a amber, r rust, p post, e earth, s shade, n night (from _UI_PALETTE in lib/foreman-ui.sh), # the silhouette (#0a0908, 232 in 256 colours), . the terminal's background. install.sh carries the 12 rows as fixed lines, once in 24-bit escapes and once in 256-colour ones, each row ending in a reset; it needs no node to print them. It prints them when ui_show says yes on stdout (stdin and stdout are terminals, no CI, FOREMAN_SHOW not never), the tier is 24 or 256 and the terminal is at least 80 columns wide.
