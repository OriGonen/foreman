10 · The install wizard (terminal)

bash install.sh asks one question when — and only when — stdin and stdout are both terminals: CLI only, or CLI + desktop app. Everywhere else (the smoke suite captures its output; CI; a pipe) it behaves exactly as today. --gui / --no-gui answer it up front for scripted installs. On a rerun it asks only about the missing piece; with everything installed it asks nothing. Installed-or-not is read from disk: gui/node_modules and the Start-menu shortcut.

This is terminal output, so it is drawn in the dark palette only (ADR 0003); a terminal too narrow or without colour gets the same words as plain lines.

Pick: a · numbered choice. Typing 1 or 2 works with a plain read in any terminal, Git Bash's mintty included; b's arrow-key menu needs raw key reading in bash, which foreman avoids everywhere but the run's own status bar — and it looks no better for one question.
