04 · The live run

Watching the same foreman run the terminal runs. The app started it (or found it already running: the batch's control directory has a pid that is alive), and reads only files: the control directory (iteration, budget, spent, live, activity, feed), the stall marker for the ticket in flight, and foreman-runs.jsonl for each finished iteration's outcome. +, − and L do what the keys do on the terminal, through foreman keys. Stop after this iteration sets the budget to the iteration running; Stop now… asks, then interrupts as Ctrl-C does.

Sample: run 20261021-2 on human-tickets. It opened with a review turn (an earlier run left work behind), 05 landed, 06 progressed, then stalled and took a checkpoint turn, and 06 is running again as iteration 4 of 5.

Pick: a · the site, by default, with c · compact as a second view. a is the terminal's run screen in a window: header with the figure and the dome, the iterations with the feed under the one running, the bar along the bottom with the same keys. Someone who has watched a run in the terminal knows where everything is. At sign-off a Full view | Compact view switch was added at the top right of a, and c is what it switches to: a small window with the dome, the ticket and its activity line, the meters, − / + and Stop after this one, and the same switch to go back. b (three columns) was not picked.
