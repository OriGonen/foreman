02 · Ticket detail, and the handoff editor

One ticket: its status line, Blocked by:, Checks: (or which followup checks it), Handoff:, the ticket text, and the progress.txt notes that mention it. For a human ticket, the one thing the app writes: the handoff file named on its Handoff: line, inside the repo, nowhere else.

The ticket itself is never edited here. Marking a human ticket done is flipping its status line in the person's editor (Open ticket in editor). All ticket, notes and handoff text is shown as text, never as HTML.

Pick: b · ticket page. The handoff file answers the ticket's criteria, so the two need to sit side by side at full height; the drawer in a squeezes both into 470px and hides the order behind a scrim for no gain. b1 shows the same page for an agent ticket, so one layout covers both.
