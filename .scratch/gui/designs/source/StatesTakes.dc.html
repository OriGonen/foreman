09 · Empty and error states

Six states the app must say plainly, each with one next step: the folder isn't a git repo; the repo has no batch; Git Bash isn't found (the app runs every command through it); claude or sbx is missing for the batch's exec mode; the agent's login has expired (a run stopped with exit 20 and auth_failed in the run log); and a batch the CLI can't read (here: order.md lists a ticket that doesn't exist — what foreman status really says about a renamed DONE_ batch today).

Every message is the CLI's own words where the CLI has them (its stderr, shown as text), so the app never invents a diagnosis.

Pick: a · a scene and one step. Each of these blocks everything below it, so it gets the whole pane: a small picture (the dome at night, the inspector with a sign, the stake line with a missing stake), what is wrong in one sentence, the CLI's message, one button. b's banner over greyed content suggests the content behind it is still current, which here it isn't.
