03 · Starting a run: the confirmation

Starting a run costs money, so Start run… always opens this first, and nothing is spawned until the person confirms. It shows the three budgets: iterations (set here, as <n> or --unlimited), FOREMAN_MAX_COST_USD and FOREMAN_MAX_MINUTES (read from foreman dry-run --json, i.e. foreman.conf and the environment; change them there). It also shows the exact command that will run. Esc or Cancel spends nothing.

Pick: a · the bill up front. Itemised like foreman report's bill, and it shows where the budget actually reaches — 05, 06, then 07 stops the run — so "10 iterations" never reads as "10 tickets". An unset cap is called out in rust rather than hidden. b is tidier but its three equal tiles weigh an unset spend cap the same as a set one.
