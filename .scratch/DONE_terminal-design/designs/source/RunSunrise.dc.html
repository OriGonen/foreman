Will --live still work?
Yes. The header and the footer are the same either way; only the middle changes.
quiet  (default)      one line per iteration; the latest tool call rolls in place
live   (--live or L)  every tool call, as the agent makes it
L      at any time    switches between them; the footer shows which is on
Flip the switch under the terminal to compare. The footer is the pinned status bar the run already has, with the elapsed time first.
